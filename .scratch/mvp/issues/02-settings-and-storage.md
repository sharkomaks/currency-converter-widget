# 02 — Настройки и хранилище

**What to build:** настройки живут в `storage.sync` по схеме (`onboarded`, `schemaVersion` (теперь 2), `lang`,
`theme`, `overlayTheme`, `targetCurrency`, `gap`, `showFlag`) и читаются снимком. Страница настроек
(первой версии, пикер валют ещё простой) меняет значения и сохраняет по факту изменения — отступ с
задержкой, у `sync` лимит на частоту записи. При загрузке работает `migrate(from, to)`: валидация всех
значений, выпавшая из списка целевая валюта переводится на USD с уведомлением в настройках, версия из
будущего не перезаписывается.
