# 08 — Онбординг и живая сцена

**What to build:** первый запуск — два экрана. Экран 1: язык → тема → целевая валюта, у всех трёх поля
дефолт из браузера (читается один раз: `getUILanguage`, `prefers-color-scheme` с фолбэком тёмная,
регион → валюта статической таблицей), кнопка «дальше», без «пропустить». Экран 2: живая сцена — то же
состояние окна, что на чужой странице; фиксированная фраза `The book costs 14,50 € today.`, подсветка
только суммы сделана CSS; окно включено постоянно и всегда сверху; числа — фикстура `14.5` → `16.10`,
печатает тот же форматтер `Intl`; сети нет — сцена одинаково выглядит в самолёте. Ползунок отступа 0–20
на сцене двигает настоящее окно. Сноска: «на странице будет ваша валюта». Флаг `onboarded` в `sync`:
второй запуск открывает настройки, вторая машина с синхронизацией — тоже (объяснять нечего). Из настроек
онбординг открывается снова кнопкой «как это работает».

**Blocked by:** 07 — Окно на странице end-to-end.

**Status:** done (2026-11-13)

- [x] Сцена показывает фикстуру без единого запроса в сеть; печатает `Intl.NumberFormat`, не строку
- [x] Ползунок на сцене двигает настоящее окно; тема сцены меняется вместе с настройкой
- [x] Сцена учит механизму: выделение суммы, а не фразы
