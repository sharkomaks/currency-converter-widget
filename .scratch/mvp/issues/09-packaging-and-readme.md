**What to build:** сборка, которую можно отдать человеку. `bun run build` даёт папку для Chrome
(распакованная, режим разработчика) и архив для Firefox (временное дополнение; `gecko.id` на месте).
Ручная проверка M5 в обоих браузерах: выделение → окно, конвертер, настройки, онбординг, лимиты
`storage.sync`, права в манифесте — только `storage` и Frankfurter. README с инструкцией для друзей,
написанной вслух: Chrome — две минуты; релизный Firefox — Developer Edition или временное дополнение
(исчезает после перезапуска), подпись AMO self-distribution — начало шага публикации. Три обещания
приватности — текст будущей политики: наружу только пары валют, аналитики нет, удалённого кода нет.
