# 03 — Пикер валют

**What to build:** один компонент пикера, живущий на странице настроек: сначала поле поиска, затем по
строке на валюту — флаг, код, название на языке настройки. Поиск находит и по коду, и по названию;
`Intl.DisplayNames` и сортировка всегда получают нашу локаль, язык браузера не читается. Смена языка
перестраивает пикер целиком — имена, порядок, поиск. Валюты без флага получают глобус; колонка флага
фиксированной ширины, чтобы строки не съезжали (в том числе с двухбуквенными «флагами» Windows).

**Blocked by:** 02 — Настройки и хранилище.

**Status:** done (2026-11-13)

- [x] Смена языка перестраивает открытый пикер: названия, порядок строк, поиск
- [x] Проход с клавиатуры целиком; контраст не ниже 4.5:1 в обеих темах
