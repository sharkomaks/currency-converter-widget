# 05 — Приложение end-to-end: ручной конвертер

**What to build:** приложение у тулбара конвертирует набранную руками сумму: два поля и два пикера,
результат пересчитывается на каждом вводе. Правило разделителей одно на весь продукт — в поле `12,50`
всегда двенадцать с половиной, независимо от валюты. Шесть классов ошибок с текстами из словаря
(заголовок, деталь с парой и кодом, кнопка, которая помогает), таймаут 8 с считается в окне, «повторить»
идёт мимо кэша, погашена на `min(2ⁿ, 30)` секунд с jitter и счётчиком. Словари `_locales/ru` и
`_locales/en` статические, формы по числу — через `Intl.PluralRules(нашЯзык)`. Результат — элемент с
`role="status"` и `aria-live="polite"`.

**Blocked by:** 03 — Пикер валют; 04 — Фоновый скрипт и курс.

**Status:** done (2026-11-13)

- [x] `12,50` в поле даёт 12,5 при любой валюте; `1.234` — 1234 (счёт цифр, критерий 20)
- [x] Шесть классов ошибок различимы на фейковом `RateSource`: у каждого заголовок, деталь с парой и

- [x] Повтор после ошибки не отдаёт кэш; двойной клик не порождает второй запрос
- [x] Тексты не собираются из кусков в коде; отсутствующий ключ выводится именем и валит сборку
- [x] Результат объявляется скринридером
