# 07 — Окно на странице end-to-end

**What to build:** контент-скрипт доводит цепочку до конца: `selectionchange` сразу →
парсер → при точном выделении скелетон → `getRate` (кроме случая «валюта совпала с целевой») → число.
Окно в `ShadowRoot`, контейнер на `documentElement`, `position: fixed`, сторона сверху, если влезает,
иначе снизу, прижатие к краю с зазором 8 px, не влезает по высоте — не показывается. Скелетон
и число одной высоты (резерв на две строки). Состояние вкладки — одно место: снимок настроек (гасится
`storage.onChanged` и `visibilitychange`), номер запроса против гонок, фаза окна. `pointerdown` на окне
гасится до страницы; «клик вне» — слушатель на `document` в перехвате; закрытие по прокрутке, снятию
выделения, клику вне. Темы: объявление страницы → первый непрозрачный фон `html`/`body` по яркости →
тема приложения; краска под выделением не читается. `overlayTheme` из настройки; флаг валюты — опция
`showFlag`, опционально после числа. Тексты ошибок — те же шесть классов, что в приложении.

**Blocked by:** 02 — Настройки и хранилище; 05 — Приложение end-to-end; 06 — Парсер.
